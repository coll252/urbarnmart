User Manual

Customer Help Center

How to use the store

  1. Browse products on the home page or shop section.
  2. Use search to find specific products.
  3. Use category filters to narrow results.
  4. Login or create an account before shopping.
  5. Add items to cart and review them before checkout.
  6. Checkout to place your order.
  7. Use your profile to see your order history.

If you get lost

  • Click the UrbanMart logo to return home.
  • Click Shop in the navbar to view all products.
  • Use the floating help button at the lower side anytime.
  • Open your cart from the bag icon.
  • Open your profile to manage orders and session.

Troubleshooting

  • If login fails, check your email and password.
  • If products do not appear, confirm the backend and database are running.
  • If cart actions fail, ensure you are logged in as a customer.
  • If images are missing, confirm uploads are available on the server.

Quick actions

  • Home: main landing section
  • Shop: all products
  • Cart: selected products
  • Profile: account and order history
Admin Manual

Admin Help Center

Admin navigation

  1. Open Dashboard for store summary and charts.
  2. Open Products to add, edit, and delete inventory.
  3. Open Categories to manage product grouping.
  4. Open Orders to update status.
  5. Open Users to view registered customers.
  6. Open Appearance to customize store colors and hero product.

Products management

  • Use Add Product to insert a new item.
  • Upload an image for better presentation.
  • Mark a product as featured to highlight it.
  • Edit or delete products from the products table.

Orders management

  • Each order lists its items and current status.
  • Use the dropdown to change status to Pending, Shipped, Delivered, or Cancelled.
  • Changes save directly to the database.

Admin troubleshooting

  • If dashboard data fails, confirm the backend includes admin routes.
  • If product save fails, check required inputs and backend connection.
  • If images do not upload, check the uploads folder and server permissions.
  • Use Back to Store to return to the public storefront.
